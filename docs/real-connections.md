# 软件连接逐项核实（2026-10-26）

本页列的是当前1.3.0实际实现的能力。手机机主是当前角色。系统打开、公开数据查询、账号授权与角色本机记录是不同能力；没有凭据/授权的账号接口保持未连接，不用合成数据代替平台回执。

| 入口 | 当前落地能力 | 官方来源/入口 |
|---|---|---|
| 备忘录 | 角色自己的便签，真实保存到插件存档。 | Skivu插件本机功能 |
| 日历 | 角色的日程与离线晨昏计算；不读取设备日历。 | Skivu插件本机功能 |
| 浏览器 | 打开公开 HTTPS 网页；读取 RSS/Atom，选择后收藏到角色浏览器。 | [来源](https://www.mozilla.org/firefox/) |
| 淘宝 | 打开真实淘宝页面；手机内订单仍是角色记录，未接入买家账号或付款。 | [来源](https://open.taobao.com/) |
| YouTube | 打开真实 YouTube；账号数据需要平台应用凭证与授权，当前不读取账号历史。 | [来源](https://developers.google.com/youtube/registering_an_application) |
| 私密空间 | 角色的私密本机记录，独立控制是否进入模型上下文。 | Skivu插件本机功能 |
| 书架 | 真实 Open Library 书目搜索，选定后加入角色书架；不提供受限图书全文。 | [来源](https://openlibrary.org/dev/docs/api/search) |
| 相册 | 用户选择文件、角色存档图片与用户配置的生图服务；不扫描设备相册。 | Skivu插件本机功能 |
| 音乐 | 通过自己配置的兼容服务真实搜索、选歌与播放；取决于该服务及账号授权。 | [来源](https://music.163.com/) |
| 地图 | 在真实 OpenStreetMap 搜索地点；角色手机内地图继续保存故事地点，不表示设备定位。 | [来源](https://www.openstreetmap.org/copyright) |
| 微信 | 可打开官方页面；个人微信聊天和朋友圈尚未获得可用的授权接口，手机内内容是角色记录。 | [来源](https://open.weixin.qq.com/) |
| 航旅纵横 | 打开航旅纵横官方页面；航班与个人行程同步接口尚未接通，角色安排保留在本机。 | [来源](https://www.umetrip.com/) |
| 哔哩哔哩 | 打开真实哔哩哔哩；账号授权与对应开放能力需单独接入，当前不同步观看历史。 | [来源](https://open.bilibili.com/) |
| Instagram | 打开真实 Instagram；账号同步需要 Meta 应用与适用账号授权，当前未连接。 | [来源](https://developers.facebook.com/docs/instagram-platform/) |
| 美团外卖 | 打开真实美团外卖页面；不把角色订单当成真实下单，不读取个人订单或付款。 | [来源](https://developer.meituan.com/) |
| 小宇宙 | 打开小宇宙，或读取节目提供的真实 RSS 保存节目资料；不声称已登录小宇宙账号。 | [来源](https://www.xiaoyuzhoufm.com/) |
| 下厨房 | 打开真实下厨房页面；当前未接通账号菜谱收藏同步。 | [来源](https://www.xiachufang.com/) |
| 豆瓣 | 打开真实豆瓣页面；当前未接通账号书影音记录同步。 | [来源](https://www.douban.com/) |
| 闲鱼 | 打开真实闲鱼页面；当前不发布商品、操作交易或读取个人订单。 | [来源](https://open.goofish.com/) |
| 微博 | 打开真实微博页面；账号读写需要开发者应用与授权，当前未连接。 | [来源](https://open.weibo.com/wiki/授权机制说明) |
| 账本 | 角色的本机账本，金额统计可用；不连接银行或真实支付。 | Skivu插件本机功能 |

公开书目采用 [Open Library Search API](https://openlibrary.org/dev/docs/api/search)，保留作品URL与作者；非全文下载。RSS/Atom按用户给定公开HTTPS源手动读取，保留原始链接，不执行订阅内HTML/脚本/实体。使用来源方公开服务需遵守其许可和使用条件；查询限速、短时缓存、响应体限制1MiB。外部查询不会自动向模型发送，模型生成也不会自动调用这些查询或进行账号操作。

音乐沿用用户自选兼容后端，需要自己配置地址及必要授权。系统跳转使用SDK `ui.openExternal` 和独立权限，宿主0.2.39起支持。HTTPS App Links能否交给对应软件取决于系统关联与安装情况，不能据此声称获得平台账号能力。浏览器独立管理账号及后续导航，不向插件返回Cookie。

仅已完成的业务/浏览器测试不能证明外部账号已授权。没有用户自己的平台应用凭证、OAuth回调与账号授权时，不启用私聊、发帖、订单、付款或平台私人历史同步。平台开放接口的具体资质/账号条件需按其当前文档进一步核实，未把搜索未找到接口表述为平台永远不提供接口。

角色工具同样使用这些真实适配器，不使用演示数据回填：phone_search_books返回公开书目与作品ID，phone_read_feed只读当前角色已保存的订阅配置，phone_open_software使用插件内部受控的站点/搜索链接并交给宿主确认。查阅结果会作为工具回执进入下一轮模型，再决定是否按用户要求写入角色自己的手机。没有用户自己的账号授权时，这些工具不提供私人平台数据或实际交易能力。
