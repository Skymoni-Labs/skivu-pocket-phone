# 角色随身手机的使用方式

手机属于当前角色。正常聊天是主要交互，手机作为随身物品参与记事、查阅和生活；用户主动打开时才展示桌面。安装不替换主聊天，不为所有角色自动生成手机，不新增全局主页面，不常驻后台。

## 初次使用

1. 更新到Skivu 0.2.41 / build45或更高，在插件市场安装并启用角色小手机1.4.0。
2. 到角色资料的“角色随身插件”，或当前聊天的插件动作设置，为这个角色绑定手机。默认仅手动使用。
3. 希望角色边聊边记事时，打开“允许随正常聊天读写本机记录”。这允许当前聊天使用手机工具，模型工具续轮可能增加本次对话的额度消耗；实际外部链接仍由宿主逐次确认。

“各故事独立”默认按每段聊天分别保存。同角色的独立剧情不会互相串记录；需要沿用跨会话生活时，用户可选择“同角色共用”。切换只改变查看空间，不删除或自动合并数据。旧角色记录可选同角色共用查看，旧共享机主可在手机设置独立查看、导出或确认迁入。

## 聊天中的体验

用户在原聊天提出记事或查阅要求，角色通过已绑定的手机工具执行。只有保存成功的真实回执才支持完成陈述。保存结果附一张记录卡，点击打开同角色、同故事的对应记录。无需先进入另一个插件聊天页。

手机里“聊聊这件事”“问问TA”会将记录带回原会话的可编辑草稿，保留用户已有草稿，不自动发送。主聊天的字体、历史、输入、群聊和其他界面插件仍归宿主管理。

“让TA更新近况”保留为用户主动触发的生成草稿功能，修改勾选后再保存。它与正常聊天中明确执行的手机操作分开。记录会标明来自角色聊天还是角色剧情补充，避免把生成经历、公开订阅和现实账号回执混为一谈。聊天更新记录可撤销；后来已被编辑的记录不直接撤销覆盖。

## 显示与运行

启用后在该角色的聊天扩展菜单出现“TA的手机”。角色资料用于管理绑定；市场用于安装和更新；有实际内容时显示消息卡片。用户不打开手机时，页面无需保留，宿主仅为一次工具短时运行并释放。停止聊天、切换角色/故事、撤销授权或App退到后台时，不继续发起后续工具与模型操作。

真实书目、RSS和软件链接仍按[21入口接入明细](real-connections.md)提供。打开网页只证明系统交接；角色本机购物、私聊和账本记录不代表现实平台交易或账号同步。现实账号能力继续需要对应平台应用和用户授权。
