# 角色小手机 1.4.0

独立的 Skivu SDK 1.0 插件，需要 **Skivu 0.2.41 / build45 或更新版本**。角色随身物品，正常聊天中按需使用，主动打开时查看手机；不替换主聊天。通过通用宿主运行，无需 Linux、Node 或额外服务进程。完整可编辑源码、许可证、测试与构建工具在本仓库公开提供。

在“插件市场 → 开放插件与开发者”刷新目录，找到“角色小手机”安装并确认权限；也可导入发行版 `.skivu.json`。再到角色资料或聊天插件动作中的“角色随身插件设置”单独绑定。默认仅手动使用，可显式开启随聊读写。新故事默认独立，选择同角色共用可沿用旧角色记录。详情见[使用体验](docs/role-phone-experience.md)。

## 轻量界面

原生 HTML、CSS、JavaScript ES Modules，复用宿主 WebView；没有 React、Vue、UI 组件库、图标字体或运行时依赖。SVG 图标和 CSS 装饰随插件离线提供，按当前应用展示记录，图片延迟载入并限制并发。1.2.0 重建桌面、21 个应用与编辑/对话界面，沿用 1.1.1 的业务模块、存档与工具协议。

本仓库独立维护插件的源码、测试、发行包和版本；插件市场仓库只登记安装 URL、manifest、大小与摘要。

## TA 的生活与软件连接

手机机主是当前角色。桌面的“TA 的近况”汇集实际保存的便签、动态、照片、歌单、书架、地点和安排。“让 TA 更新近况”通过宿主当前角色设定生成1至5条相互呼应的草稿，预览、修改和勾选后原子保存到备忘录/动态/日程；不会自动修改旧记录或操作外部账号。切换角色、范围或会话时草稿作废，其他编辑发生后旧草稿不能覆盖。

“问问 TA”将选中记录带入当前 Skivu 聊天的可编辑输入框，用户发送后使用现有多轮工具流程。“收下 TA 说过的话”读取当前宿主会话中的角色原话，编辑后保存为 TA 的便签。

“软件与服务连接”逐项列出21个入口的实际能力：已有音乐服务、Open Library 书目查询、RSS/Atom读取及系统打开公开链接。查询结果在用户选择后保存，保留来源；相同书目/订阅条目避免重复导入。公开来源不会自动提供账号权限。微信/购物/交易等当前未接通的账号能力明确标注，角色本机记录不会冒充真实平台结果。完整列表及官方来源见 [连接核实](docs/real-connections.md)。

`ui.openExternal` 需宿主0.2.39、`external.open`权限和每次确认，交由系统浏览器或关联软件处理。系统接受打开不表示登录、发送、付款、下单或播放已完成。浏览器预览使用模拟SDK；Android真实宿主和公开服务的验收另行记录。

## 功能

- 21 个应用、42 个可读写集合，兼容 `character_phone_core.character_phone_*` 的31个工具名称与主要参数结构。完整字段仍可在记录详情及编辑表单查看。
- 两页桌面与底栏、机主和社交资料、可裁剪头像、壁纸；月历与选定日期创建、离线晨昏、地点总览与跨集合地图标记、相册分组和大图。
- 购物车合计、视频及阅读进度、聊天五种消息类型与群成员、社交动态及评论收藏、航班与配送状态、菜谱食材及步骤、账本日分组和分类统计。
- 音乐通过用户自选网易云兼容服务搜索、选歌、前台播放、暂停、上一首/下一首及续播。生图通过用户自选兼容 `/images/generations` 的服务，预览后再采用。
- schema1 原版 `phone.json` / `phone.json.bak` 的显式导入；导出记录及本机图片备份；原版 `/api/media/` 图片通过同名文件迁入。其他环境中的 Cookie、密钥和图片文件不会自动搬运。

开启随聊后，原生聊天可调用三个已接入的真实服务工具：`phone_search_books(keywords)`查询公开书目；`phone_read_feed(source)`读取当前角色在浏览器或播客中配置的订阅；`phone_open_software(app,query?)`请求系统打开指定软件/网页。查询回执进入下一轮角色推理，不会自动当作角色亲历或自动写入收藏；保存仍由相应手机工具完成。平台链接与订阅地址不作为模型凭据，工具不接受任意HTTP请求头或账号参数。

## 角色与聊天

默认由宿主按角色与故事绑定存档，也可显式选择同角色跨会话共用。旧角色、旧共享机主记录保留，切换不自动合并、删除或混用。切换角色、会话、存储模式或暂停页面会取消未完成任务。

用户开启随聊能力后，正常宿主聊天使用命名空间工具，最多4轮模型、4次工具，每批最多2次；模型与计费仍走宿主既有保护路径。手机页面关闭时无需常驻，工具短时执行结束即释放，App退出后不定时生成。页面中的旧聊天控制器仅作为开发兼容代码保留，正式新宿主使用原聊天和可编辑草稿返回。

随聊工具不读取或改写私密空间；用户仍可在手机里手动查看和编辑。每轮持久保存执行意图和回执；刷新可查看或继续尚未完成的任务。无法确定是否完成的写入进入人工复核，不自动重放；已经完成的操作不会因后续失败回滚。最终聊天写入被拒绝时，继续只重试该写入。journal 与存档采用 SDK 存储；新宿主提供原子 compareAndSet，阻止页面与工具的旧存档覆盖；打开的手机通过变更事件刷新，未保存编辑保持。

## 权限与外联

申请 `external.open`、`storage`、`files`、`secrets`、`network`、`network.local`、`ai.generate`、`chat.read`、`chat.write`。网络域为 `*`，供用户设置音乐、生图和记录图片地址。全部请求经过宿主代理，没有原始 fetch、WebSocket 或远程媒体直连；不向插件提供账号令牌、模型密钥或管理员接口。

Cookie 与生图 Key 保存在插件独立 secrets 空间。空值保留，切换服务地址清除旧凭据。音乐支持公共 HTTPS 后端，或用户显式设置的字面 `http://127.0.0.1:端口` / `http://localhost:端口`；HTTP 音频仅允许与该音乐后端同一 origin，不能借此访问其他主机或端口。实际请求仍由宿主检查 `network.local`。生图服务和远程图片仅允许公共 HTTPS。模拟聊天、购物、位置、航班和转账仅为手机内记录，不操作真实平台。

## 容量与运行边界

- 手机存档合计最多6 MiB，主副存档独立；损坏时阻止覆盖，可显式恢复上一份备份。对话 journal 单独限制4 MiB。切换过程中尚未发出的保存会拒绝；已被宿主接收的单次原子保存不能撤回。
- SDK 单文件/响应上限8 MiB，图片在插件中限制5 MiB。图片多时使用“单独导出记录与图片”；分开导出的图片重新导入后按内容摘要恢复引用。
- 音乐先经宿主下载8 MiB以内音频，再用本机 Blob 播放。WebView 可能要求再次点播放，不承诺锁屏或后台持续播放。实际服务的账号、曲库、额度与兼容性需配置后单独验证。
- 晨昏使用 SunCalc 1.9.0 和 IANA 时区，提供32个城市预设及手动坐标，无天气、遮挡及地形修正。地图是本机坐标示意，不含真实地图定位或导航服务。

## 开发与复核

在仓库根目录运行：

```sh
node --test tests/*.test.mjs
python tools/build_web_plugin.py src --output /your/output/pocket-phone-1.4.0.skivu.json
python tools/build_web_plugin.py --check /your/output/pocket-phone-1.4.0.skivu.json
```

`tests/browser.cjs` 使用 `playwright-core` 与 Chromium，检查真实页面和模拟 SDK。默认使用已安装的 playwright-core 和 Chromium；可用 `PHONE_PLAYWRIGHT_PACKAGE` 指定提供 playwright-core 的 package.json、`PHONE_CHROME_PATH` 指定浏览器、`PHONE_QA_OUTPUT` 指定检查输出目录。模拟 SDK 和合成数据仅用于测试，不进入生产插件包。模拟模型测试、真实 Android 宿主测试和真实外部服务验收分别记录；不以 mock 测试代替真实账号或付费调用测试。
